# 定心 · 更新发布

本仓库用于发布 定心 的正式程序包及更新清单，应用可匿名检查与下载。源码保存在私有源码宝箱。

下载版本为 1.0.4。GitHub Releases 中的校验材料用于核对下载完整性。

## 下载

请在 [Releases](https://github.com/Markertwo/focus-timer-releases/releases/latest) 下载。Windows 用户选择 `FocusTimer-1.0.4-win-x64.exe` 安装包；需要解压即用时选择 `.zip`。安装版支持自动下载与更新，绿色版只提供下载提示。

程序尚未签名，首次运行可能出现 Windows 安全提示；请先核对同一 Release 的 `SHA256SUMS.txt`。遇到疑似误报请反馈，勿关闭系统防护。

## 反馈

在 [Issues](https://github.com/Markertwo/focus-timer-releases/issues) 提供版本、Windows 版本、复现步骤和截图；提交前遮挡项目路径、学习记录等个人信息。
